# Use-Case 用例实现规约：智能问答

---

## 1. 简介

本文档描述 ICAMPUS 校园智能问答系统中「智能问答」用例的设计与实现，涵盖用户提问、知识库检索、LLM 生成答案、问答日志记录及答案反馈的完整流程。

### 1.1 目的

阐明智能问答用例的实现方式，定义参与协作的类及其关系，为开发和测试提供设计依据。

### 1.2 范围

- 相关用例：用户提问（/api/qna/ask）、热点榜单（/api/qna/hot）、答案反馈（/api/qna/feedback）、知识贡献（/api/contribution）、管理员审核（/api/admin/audit）
- 涉及模块：api（Controller/异常处理/安全）、app（Service/DTO）、domain（实体/仓库接口/SPI）、infra（LLM客户端/Repository实现/JWT）、core（响应包装/异常）

### 1.3 定义、首字母缩写词和缩略语

| 术语 | 说明 |
|------|------|
| LLM | Large Language Model，大语言模型（通义千问/文心一言） |
| KB | Knowledge Base，知识库 |
| SPI | Service Provider Interface，服务提供者接口 |
| JWT | JSON Web Token，身份认证令牌 |
| DTO | Data Transfer Object，数据传输对象 |
| VO | View Object，视图对象（接口返回值） |
| answerSource | 答案来源：KNOWLEDGE_BASE / NOT_FOUND / LLM |

### 1.4 参考资料

- ICAMPUS README.md — 项目架构与接口契约
- Spring Boot 3.2.5 官方文档

## 3. 派生需求

### 3.1 非功能性需求

| 类别 | 要求 |
|------|------|
| **性能** | 问答接口响应时间 < 2s（含 LLM 调用）；热点榜单 < 200ms |
| **安全** | 所有接口强制参数校验；JWT 24小时过期；密码 BCrypt 加密（当前简化） |
| **可用性** | LLM 超时降级 → 返回知识库标准答案；知识库无匹配 → 返回兜底话术 |
| **可扩展** | LlmClient 为 SPI 接口，新增大模型只需实现接口即可 |
| **兼容性** | Java 17+、Spring Boot 3.2.x、MySQL 8.0+ |

### 3.2 实施注意事项

1. `answerSource` 必须正确区分：KNOWLEDGE_BASE（命中库）、NOT_FOUND（无匹配）、LLM（模型生成）
2. `questionLogId` 需在问答响应中返回，前端反馈时必须携带
3. 反馈接口需校验 `questionLogId` 存在且未重复提交
4. 管理员接口需校验角色 `ROLE_ADMIN`
5. 当前使用内存 Repository，部署前需替换为 MyBatis-Plus + MySQL
6. 当前密码为明文存储，部署前需替换为 BCryptPasswordEncoder
7. 编译器必须启用 `-parameters` 标志，确保反射可获取参数名
